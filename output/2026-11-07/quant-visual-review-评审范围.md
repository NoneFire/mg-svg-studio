# 评审范围

配套文件：`quant-visual-review-正反例表-融合版.csv`（22 条规则）。

这份声明定义边界。表里每条规则都有「适用条件与证据」，那份说明的是单条规则什么时候不适用；这里说明的是整份表什么时候不适用。

## 定位

审**静态单帧的视觉呈现**：一张固定视口、固定投放尺寸的渲染结果。

不是审交互、不是审动效、不是审内容正确性。

## 覆盖

| 类别 | 内容 |
|---|---|
| 几何 | 溢出、裁切、遮挡、对齐、网格、间距节奏 |
| 可读 | 字号下限、行长、行高、对比度、颜色线索 |
| 系统 | 组件一致性、排版档位、色彩预算 |
| 组织 | 语义分组、共同区域、分块与层级、主次焦点、信息噪音 |
| 交付 | 资源有效性、图像比例失真 |

## 不覆盖

1. **动效与时序**：动画时长、缓动、节奏、转场、关键帧、音画同步。单帧看不出，需要多帧采样或录屏。
2. **交互态**：悬停、焦点、按下、禁用、加载中、空状态、错误态。本表只审默认态。
3. **响应式**：断点行为、重排、流式尺寸。一个视口只代表一个视口，换宽度要重新评审。
4. **内容正确性**：文案准确性、数据真实性、链接指向。只审呈现，不审事实。
5. **信息架构**：只审「组织结果的呈现」——`分块与层级`、`语义分组`、`共同区域` 三条覆盖这一小块。导航结构、任务流、卡片分类方法、搜索有效性不审，这些要跨页面和用户测试才能判。
6. **主题与多语言**：暗色模式、RTL 布局、长词扩展。除非评审样本本身就是该主题，否则记不适用。

## 评审前提

- 视口与投放尺寸必须写明，且固定。
- 一律用**渲染后**的测量值。不用源码属性推算文本宽度、行高或溢出。
- 缺证据记「未测」，不记「通过」。两者不能混。

## 未测的处理

单条规则缺证据记未测，不进分子也不进分母。

同一条原则下超过一半规则未测时，该原则的得分标注「证据不足」，且不参与跨版本配对比较。

## 与其他文件的关系

- 阈值性质（规范 / 惯例 / 提案）标的是**数值**的可信度，不是规则的适用性。
- 来源类型（书籍 / 标准 / 设计规范 / 论文 / 定义）标的是**原则**的出处。
- 两列都不是质量评分，读的时候不要合成一个数。
